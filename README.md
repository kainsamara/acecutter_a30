# AceCutter

Свой софт для режущего плоттера на GRBL. Механика винилового резака
AceCutter A30 + Arduino Nano + CNC Shield V3, перо/нож - соленоид на
шпиндельном пине (D11): **M3 - перо вниз, M5 - вверх**.

Кидаешь SVG или DXF → раскладываешь по рулону → СТАРТ → режет.

## Возможности

- **Порты**: автоподключение при старте (приоритет CH340/Arduino), порт
  переключается прямо в строке; после открытия - пауза 2 с на бут GRBL,
  затем `$$` (поле станка `$130/$131` подхватывается само) и автохом `$H`.
  Тихий/не-GRBL порт: помечается «· не отвечает» и закрывается, UI не виснет.
- **Импорт SVG** (svgelements): относительные команды, transform-ы групп,
  viewBox, px→мм, флип по Y (вид как в Inkscape). Кривые → полилинии.
- **Импорт DXF** (ezdxf): LINE/CIRCLE/ARC/ELLIPSE/LWPOLYLINE/POLYLINE/SPLINE.
- **Ускорение импорта**: длина сегмента считается по контрольному полигону
  Безье (точная длина svgelements виснет на некоторых файлах по 30 с);
  **RDP-упрощение 0.08 мм** - овал r=40 мм: 4529 → 64 точки.
- **Повторный импорт добавляет** детали на поле (выше существующих,
  зазор 2 мм) - наклейки столбиком по рулону.
- **Поле-рулон**: ширина фиксирована (X), длина - валик; сетка всегда
  вписана по ширине окна, зум отключён, колесо листает рулон.
- **Контекстное меню** по вектору (ПКМ): центр по ширине / в ноль /
  вписать / повернуть / изменить / удалить. Действия - только к выделенному.
  Хоткеи работают и без меню: **C** центр, **X** в ноль, **V** вписать,
  **R** повернуть на 90° по часовой, **Enter** изменить (или двойной клик),
  **Del** удалить.
- **Изменить**: рамка с 8 хэндлами - тяни за рёбра и углы, чтобы
  масштабировать (пивот на противоположной стороне, Shift лочит
  пропорции). **Двойной клик - переключение режимов**: масштаб ->
  поворот (рамка янтарная, только 4 угла; тяни угол - вращение вокруг
  центра, дуга-стрелка с градусами, Shift - шаг 15°) и обратно.
  Ок (Enter/ПКМ) / Отмена (Esc).
  Отмена возвращает состояние на входе в режим.
- **Инструменты**: Карандаш - рисует как есть; Резак - продление реза
  на входе/выходе, дефолт 0.5 мм, чтобы наклейка легко отходила от подложки.
- **Старт**: перо M3 S1000/M5, порядок контуров «ближайший сосед»,
  проходы; прогресс по строкам в нижней строке; кнопка
  СТАРТ → ПАУЗА → ПРОДОЛЖИТЬ, Стоп = сброс + перо вверх + `$H`.
- **Живая подсветка резки**: красный путь ползёт по реальной позиции
  головки (статусы MPos, проекция на маршрут); финал - снова синие.
- **Jog**: $H, стрелки, PEN (ручное опускание пера).
- Стример GRBL с окном RX 128 байт (character counting), реалтайм
  `?` `!` `~` Ctrl-X, статусы, алармы; watchdog «GRBL не отвечает >5 с».

## Установка

```bat
cd AceCutter
python -m venv .venv
.venv\Scripts\pip install -e ".[gui,dev]"
```

Тесты (PySide6 не нужен):

```bat
.venv\Scripts\python -m pytest
```

## Использование

GUI (любым питоном, venv поднимется сам):

```bat
py launch.py
```

или классически `.venv\Scripts\acecutter`. CLI-конвертер:

```bat
.venv\Scripts\acecutter-convert деталь.svg -o деталь.nc --feed 1200
```

## Сборка в один exe

```bat
py build_exe.py
```

→ `dist\AceCutter.exe` - один файл, Python не нужен. Первый запуск
2–4 с (onefile распаковывает себя во temp) - это норма.

## Станок: что важно

| Параметр | Значение | Смысл |
|---|---|---|
| `$100/$101` | 36.36 / 32.00 | шагов/мм X (каретка) / Y (валик) |
| `$130/$131` | 245 / 2000 мм | рабочее поле (читается по `$$` автоматически) |
| `$30` | 1000 | S-шкала для M3 |
| `$22/$23` | 1 / 1 | homing включён |
| `$32` | 0 | laser mode не нужен (перо, не лазер) |

Перо: соленоид через MOSFET на D11, active HIGH. После сброса GRBL S=0,
поэтому всегда `M3 S1000`, а не голый `M3`.

## Архитектура

```
src/acecutter/
├── domain/      # Point/Transform/Polyline, раскладка, RDP - чистая математика
├── io/          # импорт SVG/DXF → list[Polyline] в мм
├── toolpath/    # ToolHead (перо M3/M5), overcut, компиляция GCode
├── driver/      # Transport ABC, SerialTransport (write_timeout), стример, мок
├── ui/          # PySide6: канвас (поле, гизмо, подсветка), главное окно
└── cli.py       # конвертер командной строки
```

Правило границ: `domain`/`io`/`toolpath`/`driver` не знают про Qt и
тестируются без станка; `ui` - тонкий слой. Критичные механики покрыты
pytest и offscreen-смоуками.
